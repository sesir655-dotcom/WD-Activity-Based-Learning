## Technologies Used
- HTML5 for page structure
- CSS3 for responsive layouts, cards, animations/transitions, and visual styling
- JavaScript for navigation menus, filtering, demo forms, and basket calculations

## How to Run
1. Download or clone this repository.
2. Open any case-study folder.
3. Double-click `index.html` or open it in a web browser.
4. Internet access is needed for the external Google Fonts and Unsplash photos. The rest of the layout and JavaScript are local.
